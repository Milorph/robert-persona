# robert-persona

Personal website of Robert Winston Widjaja, styled as a Persona 3 game menu.

Live at: https://milorph.github.io/robert-persona/

Software Developer (MDO Tools, Advanced Design) at Bombardier. Machine learning
is the main quest: aiming at data scientist and software engineer roles.

## Controls

Arrow keys to navigate, Enter to confirm, Esc to go back. Q/E flip pages on the
GitHub list in Socials. Sound toggle bottom-left.

## Stack

React + Vite + framer-motion. Deployed to GitHub Pages via the gh-pages branch
(`npm run deploy`).
